# US Company Revenue Rankings

A Python web scraping project that extracts and organizes data on the largest companies in the United States by revenue from Wikipedia.

## 📌 Project Overview
This project uses web scraping techniques to collect structured data from Wikipedia and transform it into a usable dataset for analysis. It focuses on the largest U.S. companies ranked by revenue.

## 🚀 Features
- Scrapes real-world financial data from Wikipedia
- Extracts structured tables using BeautifulSoup
- Cleans and organizes company revenue data
- Exports data for further analysis (CSV format)

## 🛠️ Tech Stack
- Python
- Requests
- BeautifulSoup (bs4)
- Pandas

## 📊 Example Use Cases
- Analyze top revenue-generating companies in the U.S.
- Build dashboards or visualizations
- Track changes in company rankings over time
